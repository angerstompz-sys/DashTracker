# Assets Directory

This directory contains app assets such as icons and splash screens.

## Required Assets

To complete the app setup, add the following assets:

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (48x48px)

You can generate these assets using online tools or design them yourself.

## Temporary Placeholder

For development, you can use placeholder images until you have final assets ready.
